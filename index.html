Kalender

Kalender abonnieren

Mit „Abonnieren“ erscheinen alle Prüfungen automatisch in deinem eigenen Google-Kalender.

So fügst du den Link ein
  • iPhone: Einstellungen → Kalender → Accounts → Account hinzufügen → Andere → Kalenderabo hinzufügen → Link einfügen.
  • Outlook: Kalender → Kalender hinzufügen → Aus dem Internet abonnieren → Link einfügen.
  • Android / andere: „Kalender aus URL“ oder „Internetkalender“ wählen → Link einfügen.

Infos

So trägst du eine Prüfung ein
  • Termin im Google-Kalender „Prüfungen BM (von Elias)“ erstellen.
  • Das Fach im Titel nennen, z. B. „Mathe Prüfung“ oder „T&U Prüfung“.
  • Wörter wie Abgabe, Frist, Nachprüfung oder Kurzprüfung erzeugen ein Zusatz-Label.
  • Ort (Zimmer) und Beschreibung (z. B. Themen) werden mit angezeigt.

Einträge ändern können nur Elias und freigegebene Personen. Bei Fragen oder fehlenden Prüfungen wende dich an Elias.
